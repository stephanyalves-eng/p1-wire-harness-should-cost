# Data sources

Raw files live in `data/raw/` and are never committed. Processed outputs go to `data/processed/`.

| Dataset | Source | Link | Extraction date | License |
|---------|--------|------|-----------------|---------|
| NCM reference table (8544.30.00, 8536.69.10, 8536.69.90) | Comex Stat API, MDIC | https://api-comexstat.mdic.gov.br/tables/ncm | 2026-11-23 | Brazilian open data |
| Synthetic purchasing base (suppliers, materials, purchase orders, quotes) | Generated by `python -m src.generate.purchasing`, seed 42 | [docs/assumptions.md](../docs/assumptions.md) | Regenerated on demand | MIT (generated) |
| Import duty (II) per NCM, in `data/reference/import_duty.csv` | TEC reference rates (Resolução Gecex nº 272 and amendments) | https://www.gov.br/mdic/pt-br/assuntos/camex/resolucoes/gecex/resolucoes-compiladas | 2026-11-26 | Public |
